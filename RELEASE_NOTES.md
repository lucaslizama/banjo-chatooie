Fixes and settings for the chat panel and the channel point reward.

## Chat panel

- Usernames no longer overlap the message beside them.
- Long messages no longer run outside the panel to the right.
- The panel is wider by default, and **Chat Panel Width** is a new setting. It
  applies while you play.

## Channel points

- **Reward Name** is a new setting. Name the reward from the mod's options and it
  is renamed on your channel a few seconds later, without restarting anything.
- Fixed: the helper script created a second reward every time it started once the
  name had been changed. It now keeps the one it made.

## Also

- The mod has a thumbnail in the mod menu.

## Still untested

Nobody has run this on a live stream, and the channel points feature has only
talked to Twitch's mock server, so signing in and creating the reward on a real
account are unproven.

Blubber may, in rare timing, read out a chat message instead of his own
first-meeting line. Report it if you see it.
